# 軽貨物まるごとアプリ

軽貨物ドライバー向けの「点呼・業務簿・お金まわり」をひとつにまとめたスマホアプリです。
北上さん＋同僚ドライバーが、それぞれ自分のスマホで使います。

> ## 作りの方針：1社1アプリ（2026-09-03〜）
>
> **1つのアプリに複数社が相乗りするのではなく、会社ごとに別のアプリ・別のFirebaseを用意して渡します。**
> サーバー代（Firebase）は各社が契約します。詳しくは下の「開発者向け」を読んでください。
> 方針の正本: `OneDrive\デスクトップ\claud code\projects\軽貨物まるごとアプリ\方針_1社1アプリ_2026-09-03.md`

## 公開URL

**https://nylonman1109-prog.github.io/keikamotsu-app/**

このURLを開けばそのまま使えます。ホーム画面に追加すれば、普通のアプリのようにアイコンから起動できます（手順は下記）。

## 使い方（かんたん3ステップ）

1. 上のURLをスマホのブラウザ（Safari／Chrome）で開く
2. 「新規登録」からメールアドレスとパスワードを決めて登録
3. ログインしたら、下のタブ（ホーム／レシート／個数／グラフ／🚛運行記録）を使って記録していく

- 収入・経費は「ホーム」の「収入を記録」ボタンや「レシート」タブから
- 配達個数は「個数」タブから
- 点呼簿・業務簿・車両点検は「🚛運行記録」タブから
- 「今月の損益」は自動でホームに表示されます

## 同僚への配り方

同じURL（https://nylonman1109-prog.github.io/keikamotsu-app/）を送るだけです。
各自が自分のメールアドレスで新規登録すれば、データは自動的に本人だけのものとして分かれて保存されます（他人のデータは見えません）。

## まとめ役について

北上さんのアカウント（nylonman1109@gmail.com）は「まとめ役」として、ホームの「👥全員を見る」からメンバー全員の状況（今日の配達個数・損益など）をまとめて確認できます。他のメンバーは自分の分しか見えません。

## ホーム画面に追加する（アプリのように使う）

### iPhone（Safari）

1. Safariで公開URLを開く
2. 画面下の「共有」ボタン（四角から矢印が上に出ているアイコン）をタップ
3. メニューを下にスクロールして「ホーム画面に追加」をタップ
4. 名前はそのまま（「軽貨物まるごと」）で右上の「追加」をタップ
5. ホーム画面にアイコンが増える → タップすればブラウザのアドレスバー無しでアプリのように起動

### Android（Chrome）

1. Chromeで公開URLを開く
2. 右上の「︙」（縦三点メニュー）をタップ
3. 「アプリをインストール」または「ホーム画面に追加」をタップ
4. 表示された内容を確認して「インストール」（または「追加」）をタップ
5. ホーム画面／アプリ一覧にアイコンが増える

一度追加すれば、2回目以降はオフラインでも画面の外枠（ログイン画面など）はすぐ表示されます。ただし実際のデータ（売上・経費・配達個数など）はインターネットに繋がっていないと読み込み・保存ができません。

## 開発者向け：フォルダの役割

```
keikamotsu-app/
├── index.html            … 北上さんの会社ぶん（公開中のもの）
├── sw.js / manifest.json / icons/
├── firebase_rules.json   … 北上さんの会社ぶんのセキュリティルール
├── template/             ★1社ぶんの雛形。機能を直すときは必ずここを直す
│   ├── index.html        … 先頭の TENANT ブロックだけが会社ごとの差分
│   ├── sw.js / manifest.json / icons/
│   └── firebase_rules.json
├── deploy/<会社ID>/      … 会社ごとの生成物。手で直さない（作り直すと消える）
└── tools/新しい会社ぶんを作る.js
```

### 新しい会社ぶんを作る

```bash
node "tools\新しい会社ぶんを作る.js"
```

聞かれるのは5つ（会社ID・会社名・営業所名・**まとめ役のメール〈複数可・カンマ区切り〉**・Firebaseの接続情報）。
設定ファイルからも作れます:

```bash
node "tools\新しい会社ぶんを作る.js" 設定.json
```

出来上がった `deploy/<会社ID>/導入手順.md` に、その会社ぶんの手順が全部書いてあります。

### 直すときの決まり

1. **機能の修正は `template/` に入れる。** `deploy/<会社ID>/` を直接いじらない
2. **会社ごとの差は `index.html` 先頭の `TENANT` ブロックだけ。** 会社名やメールをそれ以外に直書きしない
3. **`TENANT.managerEmails` と `firebase_rules.json` の中のまとめ役メールは必ず同じ顔ぶれ**（生成スクリプトが両方に入れる。片方だけ直しても効かない）
4. **`sw.js` の `CACHE_VERSION` は更新のたびに上げる。** 上げ忘れるとドライバーのスマホに更新が届かない
5. 稼働中の会社ぶんを直すときは、先にテスト用の会社IDで確かめる（提出物を扱っているため）

### 権限の決まり（1社の中）

| 役割 | できること | なり方 |
|---|---|---|
| まとめ役（何人でも） | 全員の記録を見る・承認・停止・帳票・経営レポート・まとめ役の任命／解任 | ①`TENANT.managerEmails` に載っているアドレスで登録する ②既にいるまとめ役が「👑 まとめ役にする」で任命する |
| ドライバー | 自分の記録だけ | 登録すると「承認待ち」。まとめ役が承認して使えるようになる |
| owner（サポート管理者） | まとめ役の全機能。他の人の画面には出ない | Firebaseコンソールで `role` を `owner` にする |

- 会社をつくった1人目のまとめ役と、自分自身は「まとめ役を外す」できません（誰も承認できなくなる事故を防ぐため）。
- ⚠️ **納品時は、ドライバーより先にまとめ役を登録してもらうこと。** 他人にそのアドレスで先に登録されると乗っ取られます。

### 北上さんの会社ぶんを更新する

1. `index.html`（リポジトリ直下）を直す
2. `git add` → `git commit` → `git push`
3. 数分でGitHub Pagesに自動反映される

アイコンやPWAの設定は `manifest.json` / `icons/` / `sw.js` を編集してから同様にpushします。

## 困ったときは

- ログインできない／データが表示されない → 電波（Wi-Fi/モバイル通信）が繋がっているか確認
- 表示が崩れる／古いままに見える → ホーム画面のアイコンから一度アプリを完全に閉じて開き直す
